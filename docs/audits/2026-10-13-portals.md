# Cross-portal reliability audit — 2026-10-13

Scope: route/access review, shared authentication lifecycle, manager/employee/supplier ERP portals, full existing regression suite. This is a bounded engineering audit, not certification of every ERP process.

## Confirmed defects repaired

- ERP role gate checks approval status independently of active status and blocks inactive accounts. Inventory forecasting now uses the same inventory permission gate as sibling routes.
- Late authentication responses cannot restore a signed-out user. Failed/null profile refreshes clear stale identity; completed requests clear their timeout.
- Manager, employee and supplier data reads propagate service errors into a retry state rather than presenting empty financial totals or attendance actions. Loading/missing-profile states are explicit.
- Read-only production information_schema inspection confirmed `created_date` (not `created_at`) on orders, invoices, expenses, tasks and announcements. Corrected those queries. Inventory uses product_name, low_stock_threshold and average_cost through explicit aliases.
- Purchase order items are stored on the order; nonexistent purchase_order_items embedding removed. Shipment update no longer writes nonexistent shipped_at, checks current approved status and supplier identity, and requires an affected row before reporting success.
- Manager trend adds all daily rows; amount strings are coerced before addition. Treasury honors out direction and explicitly labels its latest-20 movement window. Partial operating figures no longer claim net profit or account cash balance.
- Inventory valuation and supplier orders/invoices load paginated records instead of silently capped totals. A later page failure rejects the complete result.
- Supplier balances include partial payments, preserve explicit zero paid amounts, exclude void/cancelled/rejected invoices, and keep currencies separate. No currency conversion is performed.

## Validation

- Baseline: 148 test files / 862 tests passed.
- Updated suite plus targeted tests: 151 files / 874 tests passed (including 12 new tests for authentication races, approval conflicts, pagination failure, currency separation and failed portal reads).
- Source ESLint: zero errors; production bundle build succeeds.
- Production schema inspection was read-only. No live financial records were edited for testing.

## Remaining verification and limits

- Authenticated end-to-end sessions for every real role/branch were unavailable. RLS/payment/attendance writes were not exercised against live customer data.
- Full accounting certification, all subscription-provider failure modes, historical data quality and device/browser combinations remain outside this release's verified coverage.
- Manager pending-order/invoice panels remain limited recent queues; treasury is a latest-20 movement summary, not a bank reconciliation. Full reports remain the place for reconciliation. Manager currency/base-currency consistency and business-timezone rules need a separate focused review.
- Existing test-suite warnings and build-plugin environment notices remain; there are no new dependency updates or schema migrations in this release.
